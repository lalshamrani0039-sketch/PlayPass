# ⚽ PlayPass — منصة السياحة الرياضية

منصة ويب عربية كاملة (RTL) تربط اللاعبين بالأندية الرياضية حول العالم: استعراض الأندية حسب الدولة، تقديم طلبات الزيارة، متابعة الحالة (قيد المراجعة / مقبولة / مرفوضة)، وعرض جدول الزيارة بعد الموافقة — مع لوحتي تحكم للنادي والمشرف.

## ▶️ التشغيل (بدون أي تثبيت)

المشروع **Static خالص** — لا يحتاج Node ولا قاعدة بيانات ولا مفاتيح API:

1. افتح مجلد `C:\PlayPass`.
2. شغّل أي سيرفر محلي، مثلاً:
   ```powershell
   cd C:\PlayPass
   python -m http.server 8080
   ```
   ثم افتح `http://localhost:8080/index.html`
3. أو: افتح `index.html` مباشرة بالنقر المزدوج (يعمل، لكن السيرفر المحلي أفضل).

## � honest — الوضع الحالي للتخزين (بشفافية)

- **لا يوجد backend حقيقي بعد.** البيانات (المستخدمون، الأندية، الطلبات، الجداول) تُحفظ في **`localStorage`** بالمتصفح عبر طبقة `DB.*` في `js/store.js` — وهذا **وضع تجريبي موثّق** للعرض والتطوير، وليس قاعدة بيانات إنتاجية.
- **تسجيل الدخول محاكاة محلية** (مقارنة بريد/كلمة مرور من البيانات التجريبية) وليس مصادقة آمنة.
- **التصميم جاهز للربط:** كل قراءة/كتابة تمر عبر `DB.*` — لربط API حقيقي استبدل دوال `DB` بنداءات `fetch('/api/...')` دون لمس الصفحات. نقاط الربط المطلوبة مستقبلاً: `POST /api/auth/login`، `GET/POST /api/clubs`، `GET/POST /api/requests`، `PATCH /api/requests/:id/status`، `GET/POST /api/schedules`.

## 🌐 خدمات خارجية

- **خط Tajawal من Google Fonts** (CDN، اختياري — يوجد Fallback لخطوط النظام عند انقطاع الإنترنت). لا مفاتيح API ولا خدمات أخرى. لا يُرسل أي بيانات لأي طرف ثالث.

## 🎨 المزايا المنفذة

- عربية كاملة RTL، خط Tajawal، تكبير/تصغير الخط (A+/A-) محفوظ، وضع ليلي/نهاري 🌙☀️ محفوظ.
- ألوان رياضية (أخضر + كحلي + ذهبي)، بطاقات أنيقة، حركات خفيفة، متجاوب (كمبيوتر/تابلت/جوال)، دعم `prefers-reduced-motion` وسهولة الوصول (skip-link، عناوين ARIA).
- 9 أندية واقعية: الهلال 🇸🇦، برشلونة 🇪🇸، بايرن 🇩🇪، الأهلي 🇪🇬، أياكس 🇳🇱، ساو باولو 🇧🇷، طوكيو 🇯🇵، سيدني 🇦🇺، الرجاء 🇲🇦.

## ✅ الاختبار اليدوي السريع

1. ادخل كلاعب → استعرض الأندية → صفِّ حسب «إسبانيا» → افتح برشلونة → قدّم طلباً → تحقق أنه ظهر في «طلباتي» بحالة ⏳.
2. اخرج وادخل كنادٍ (`club@playpass.sa`) — لن تجد طلب برشلونة (خاص بنادٍ آخر)؛ جرّب: كلاعب قدّم طلباً للهلال → كنادٍ اقبله ✅ وأضف موعداً من تبويب الجداول.
3. عُد للاعب → «طلباتي» → «عرض الجدول» 📅 يظهر، وجرّب طلباً مرفوضاً للتأكد من حجب الجدول ⛔.
4. ادخل كمشرف → تحقق من الإحصائيات وإضافة نادٍ جديد.
5. بدّل الثيم والخط وحدّث الصفحة للتأكد من الحفظ.
